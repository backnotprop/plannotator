# Interactive Goal Setup UI

Create a new Plannotator goal setup UI that batches the setup-goal interview into one fast interactive session, adds a structured facts acceptance surface with automated-verification selection, and updates the setup-goal skill text so agents use the new UI instead of asking interview questions one at a time.

Use `goals/interactive-goal-setup-ui/facts.md` as the approved outcome contract.
Use `goals/interactive-goal-setup-ui/plan.md` as the approved execution plan.

Done means the skill instructions, shared data model, Bun/Pi runtime support, editor UI, facts acceptance behavior, dependency/package updates, tests, builds, and manual browser checks described in the approved plan are complete or any remaining blocker is explicitly documented for the user.
