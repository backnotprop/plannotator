SpacesHandOne.woff2 is a renamed subset of Reenie Beanie by James Grieshaber, under the SIL Open Font License 1.1 (see OFL-reeniebeanie.txt).
SpacesHandTwo.woff2 is a renamed subset of Kalam Regular by Indian Type Foundry, under the SIL Open Font License 1.1 (see OFL-kalam.txt).

Both are Modified Versions in the licence's sense: cut down to basic Latin letters, digits and punctuation, and saved as woff2. Nothing else was changed. The original copyright notice is kept inside each file. "Reenie Beanie" is a Reserved Font Name, so the subset does not carry it as its family, full or PostScript name; Kalam declares no Reserved Font Name and was renamed the same way. The page's CSS still calls the families "Hand" and "Hand2".

inter-latin-wght-normal.woff2: Inter, see OFL-inter.txt. geist-mono-latin-wght-normal.woff2: Geist Mono, see OFL-geist.txt.
