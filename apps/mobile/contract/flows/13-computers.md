# 13. Several computers

The switcher lists every paired computer, and under each the machines linked to it, with state: here, asleep since 9:12, needs an update.

- **All computers** merges the lists; each row then names its computer after the project ("api-server · Work Mac").
- A thread always lives on one computer; a reply goes to that one. When that one is away the write is held for it, with its name in the line.
- A computer whose Plannotator is older shows what it can: features it lacks are not offered on its threads, and nothing is said about it. Below the oldest version the app can talk to, its row reads "Update Plannotator on Home Mac" and its threads are not listed.
- **Pair another** opens the camera. **Remove** on a computer's row removes this phone there and erases that computer's copy and keys from the phone.
- Start an agent asks "On" which computer when there is more than one.

Linked machines seen through a paired computer need no second pairing. Pairing a second computer directly is for one that is not linked, or to reach it when the first is asleep.
