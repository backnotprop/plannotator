# 4. A thread

On screen: Back; the thread's name over "agent · project"; the More menu. Then the messages, oldest first. Read messages are folded to one line and a long run hides behind "Show 6 earlier messages", by the Inbox's own folding rule. The view lands where the window lands: at "New since you looked" when there is news, else at the last message. Below the last message, the run line when an agent the Inbox started is at work ("Claude Code is working · 6 min", Stop). At the bottom, the composer.

An agent's message is plain text on the page, never a bubble: headings, lists, tables that scroll sideways, code with highlighting and a copy button, pictures (tap for full screen with pinch), link cards, diagrams and math. A live HTML block and a diagram draw in a small sandboxed web view set into the message. The person's own messages sit to the right on a tinted ground with the delivery line under them ("Delivered to Claude Code", "Queued · Send now", "Will send when Work Mac is back").

Things in a thread:

- **Files**: a strip of tiles under the message that carries them. Tap one: section 7.
- **Questions**: cards in place. Section 5.
- **Action items**: a row with Done and Can't do it; the answer goes after a 10 second Undo, as the door does today.
- **A permission prompt** from a started agent: a card with the tool, what it wants, Allow and Deny.
- **A command to run, a secret to give**: section 10.
- **Steps**: the agent's checklist as a fold at the top of the thread ("3 of 7 done"), when the Checklist is on at the computer.
- **Select words** in any message: the system selection with Comment and Quote first in its menu. Comment opens a small sheet; the comment rides with the next Send.
- **React**: press and hold a message for Looks good and the reactions, Copy, Quote, Share.
- **More menu**: Star, Snooze, Mark unread, Archive, Delete, Priority, Tag, Send to another session, Copy attach command, the thread's pull requests, Export.

Differs from the window: the thread panel beside the thread (files, artifacts, pull requests) becomes entries in the More menu and the header line. Hover cards open on tap as a sheet.
