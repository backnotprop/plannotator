# 14. An agent that is running (live status)

Three places, one source (the run state the computer reports):

1. **The Agents tab**: "Working now", with the state word, minutes and steps.
2. **The thread**: the run line under the last message.
3. **A Live Activity** on the lock screen and in the Dynamic Island: "2 agents working · 1 is stopped on you", with Open. It starts when the person starts an agent from the phone or turns on "Follow" for a thread, updates from pushes, and ends when the work stops or after eight hours. It carries counts and state words only, never a name, a project or a line of text, because that update cannot be sealed.

A widget for the Home Screen shows the same counts and the first row that waits on the person.
