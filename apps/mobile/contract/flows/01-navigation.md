# 1. Navigation model

Four tabs and one switcher.

| Place | What lives there | The window's twin |
|---|---|---|
| **Inbox** tab | The list in the Inbox's six sections, Starred, Snoozed, the filters, Archived (from the filter menu), a thread, its files | The list, the sidebar's Inbox, Starred and Projects rows |
| **Agents** tab | Agents working now, agents stopped on you, routines ("Scheduled"), agents that ended today; the plus starts one | The sidebar's Agents section, the run line, Settings' routines list |
| **Board** tab | The Board, one lane per page; a card; New card. The tab shows only while the Board is on at the computer | The Board page |
| **Search** tab | Search across threads, messages and files; recent searches kept on the phone | Search |
| **Computer switcher** (the name at the top left of every tab) | The paired computers and their linked machines, each with its state (here, asleep since, needs an update); All computers; Pair another; then Settings and What's new | The sidebar's machine captions, Settings |

Where the rest lives:

- **Projects**: a filter, not a place. The pills under the title hold All, Unread, Starred, Pull requests and the projects with something waiting; "More" opens the full project list with its menu (Mark all read, Mark all unread, Resolve). A project's page is the Inbox tab filtered to it.
- **Pull requests**: a filter pill on the Inbox tab, a line on a thread's header, and a sheet for one pull request (state, checks, branches, the description). Not a tab.
- **Compose** (New message, which is also how an agent is started): the pencil at the top right of the Inbox tab and the plus on the Agents tab open the same sheet.
- **Settings**: at the foot of the computer switcher. Look (theme, text size, rows, following the computer), notifications, the paired computers and how each is reached, Remove this phone, About. Managing the computer itself (update, restart, accounts and the rest of the window's Settings) is not in the first version; section 15 is the design for when it comes.
- **A thread** always pushes onto the tab it was opened from; Back returns there. A push notification opens the thread on the Inbox tab with the list behind it.

Why tabs and not the window's sidebar sheet: on a phone the three questions are "what needs me", "what is running" and "where does the work stand". Each gets one thumb press. The window answers the second one in a sidebar section and a line under a message; on a phone that is the most looked-at thing after the list, so it gets a tab. This is the largest deliberate difference from the window.

iPad (after v1): the same tabs become a sidebar, the list sits beside the thread, a file opens beside the thread, as the window does from about 1052 px.
