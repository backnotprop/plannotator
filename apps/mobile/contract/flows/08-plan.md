# 8. Approving a plan or sending feedback on it

A plan an agent sends for review arrives as a thread whose first file is the plan. The thread shows the plan's title and two actions under the message: **Approve** and **Send feedback**.

1. Tap the plan: it opens as a Markdown document (section 7). Select words to comment, or add a comment on the whole plan.
2. Back in the thread, "Send feedback" is live once there is a comment or words in the composer; it sends them as one message, in the window's own feedback format, and the agent is woken.
3. "Approve" sends the approval at once. An Undo banner is not offered here, because the agent starts work on approval; the button says "Approve" and nothing else.

The Plans library (every past plan, on by a switch at the computer) is later; it is off by default in the product today.
