# 9. Starting and stopping an agent

**Start.** The pencil or the plus opens New message. Words first, then four rows: To (a live session, or "A new Claude Code session", "A new Codex session", "A new Pi session"), On (which computer), Folder (the computer's recent folders and projects first; "Another folder" browses the computer's folders, makes a new one, or clones a repository from a pasted address), Full permissions (a switch, with the window's own lines), Model (the computer's choices, default first). Start sends it. The thread opens with the run line "Starting Claude Code in api-server…".

When a folder is not trusted yet, the run line says so with **Trust folder**; one press, the same write as the window's.

**While it runs.** The Agents tab lists it under "Working now" with what the computer reports: the state word, the minutes, the step count when the agent keeps a checklist. In the thread, the run line shows the same.

**Stop.** "Stop" on the Agents row, on the run line, and on the Live Activity. One press, no question asked first, as in the window. The line then reads "You stopped Claude Code at 9:47. Your reply starts it again."

**When it could not start or answer.** "Claude Code didn't start. <cause> Your message is kept." with Try again.

Never on a phone: Open in Terminal. "Copy attach command" is offered in its place.

Delete a started session is in the thread's More menu and asks first, with the window's own words (it names the scratch folder that goes with it).

Differs from the window: the Agents tab.
