# Plannotator Review (Mistral Vibe)

Run:

```bash
PLANNOTATOR_ORIGIN=mistral-vibe plannotator review
```

You may append an optional PR URL:

```bash
PLANNOTATOR_ORIGIN=mistral-vibe plannotator review <pr-url>
```
