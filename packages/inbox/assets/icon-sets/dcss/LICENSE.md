# Dungeon Crawl Stone Soup tiles: licence

**CC0, as the project's own files state it. 419 icons, all from the project's cleared release folder.**

- Source: https://github.com/crawl/tiles, commit a6ea1655db5c (2020-09-04), `releases/Nov-2015/mon/` only (772 monster
  tiles).
- The project's licence statement (its README): artists "have signed off their copyright, returning these tiles to a
  license similar to "public domain", CC Zero", and "every care possible has been taken to separate those tiles
  released into CC Zero from those who have not or can not be contacted". The repository has no LICENSE file; the
  README, `ARTISTS.md` and `TILES_UNDER_UNKNOWN_LICENSE.md` are the licence.
- `TILES_UNDER_UNKNOWN_LICENSE.md` lists 1,264 entries "not eligible for reuse … excluded from any release". None of
  the 4,357 files in `releases/Nov-2015/` has a name on that list (checked by file name, 2026-11-10), so this set is a
  subset of the cleared release.
- 353 of the 772 were left out for fit, none for licence: tentacle segments, body parts, animation frames, ice and ghost
  copies, statues, colour copies, tall tiles, overlays, floating weapons.
- Residual risk: the clearance rests on a 2010 approval list plus the assertion that it covers later art. It is the
  project's own position for the 2015 release, and OpenGameArt lists the set as CC0.
- Credit shown anyway: "Dungeon Crawl Stone Soup tiles (CC0), https://github.com/crawl/tiles".
- Names come from the file names (`orc_wizard.png` → "Orc wizard").
