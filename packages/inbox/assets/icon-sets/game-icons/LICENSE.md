# game-icons.net creatures: licence

**CC BY 3.0 per author (one icon CC0). Shown with a credits line in the picker and the credits file here.**

- Source: https://github.com/game-icons/icons, commit 82d948812bfe (2026-04-23). Its `license.txt` (kept here as
  `UPSTREAM-LICENSE.txt`): "Icons provided under the Creative Commons 3.0 BY or CC0 if mentioned below", and "Please,
  include a mention "Icons made by {author}" in your derivative work."
- Which icons: the site's animal, bird, fish, insect, mammal, reptile, tentacle, creature, vampire, zombie and robot
  tags (573 icons), minus 239 removed by eye: 229 that are not creatures (objects, food, body parts, emblems) and 10
  that copy other companies' characters (Bullet Bill, Thwomp, Metroid, Morph Ball, Samus's helmet, Quick Man, Magnet
  Man, Purple Tentacle, the Diablo skull, the Twitter bird). 334 kept.
- Changes: the black background square removed and the fill set to `currentColor` (the Inbox draws each icon in the
  theme's text colour). CREDITS.md says so too.
